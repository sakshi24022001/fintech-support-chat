
# 💬 FinTech Support Chat Application

A full-stack real-time chat application built using **React**, **Node.js**, **Express**, **MongoDB**, and **Socket.IO**, designed to simulate a FinTech customer support chat system with authentication and protected routes.

---

## 🚀 Features

- 🔐 User Authentication (Login with JWT)
- 🛡️ Protected Routes (Only logged-in users can access chat)
- 💬 Real-time Chat Interface
- 🧠 Context API for Global State Management
- 🗂️ Modular Frontend & Backend Architecture
- 🌐 REST APIs with Express
- 📡 WebSocket-based Messaging (Socket.IO)
- 🧪 Seeded Test User for Easy Login

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- React Router DOM
- Axios
- Context API
- Custom CSS (no Tailwind dependency)

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- Socket.IO
- JWT Authentication
- bcryptjs
- dotenv
